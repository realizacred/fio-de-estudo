# Fio de Estudo

Digite um tema e o app busca estudos acadêmicos (OpenAlex) e monta um mapa mental em que cada ligação explica como um ponto leva ao outro. Clique em qualquer ponto para ver **o fio** completo desde o tema central, e use "Aprofundar este ponto" para descer mais níveis sem perder a coerência.

## Como usar

1. Abra o site.
2. Em "Configurar a IA", escolha **Gemini** (cota grátis, chave em https://aistudio.google.com/apikey) ou **Claude** (pago por uso, chave em https://console.anthropic.com).
3. Cole a chave, clique em "Salvar neste navegador" e busque um tema.

A chave fica guardada só no seu navegador e é enviada direto para o serviço escolhido. O site não tem servidor.

## Hospedagem

Arquivo único `index.html`, publicado pelo GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).
